## 📋 Sobre o Projeto

O **ERP ProGestão** é um sistema de gestão empresarial completo, desenvolvido com foco em usabilidade e design moderno. O sistema conta com um **Motor CIP exclusivo** (Central Inteligente de Produtos) que realiza busca automática de imagens de produtos utilizando inteligência artificial.

O projeto está em constante evolução, com o objetivo de se tornar uma plataforma **SaaS multi-empresarial** no futuro.

## 🚀 Como Acessar

### Online
O sistema está hospedado gratuitamente no **GitHub Pages**:
> 🔗 **(https://rodrigolordroyale3-design.github.io/erp-progestao/)**

### Localmente
Para rodar o sistema no seu computador:

1. **Baixe o arquivo `index.html`**
2. Abra com qualquer navegador moderno (Chrome, Edge, Firefox)
3. Clique em **"Começar com Dados de Exemplo"** para testar

> 💡 **Não precisa instalar nada!** O sistema roda diretamente no navegador.
